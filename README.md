# DeutschDotNet

DeutschDotNet is a compiler for **Deutsch#**, a small programming language with German keywords. It compiles `.deu` files into executable .NET assemblies.

## Requirements

- [.NET 10 SDK](https://dotnet.microsoft.com/download)

## Install

### Install globally from this repository

Run these commands from the repository root. This packs the compiler as a .NET tool and installs the `dotnet-de` command for your user:

```powershell
dotnet pack source/DeutschDotNet/DeutschDotNet.csproj --configuration Release --output source/nupkg
dotnet tool install --global dotnet-de --add-source source/nupkg
```

Check the installation:

```powershell
dotnet-de --version
dotnet-de --help
```

If `dotnet-de` is not recognized after installation, restart your terminal and check that the .NET global tools directory is on your `PATH`.

### Update the global installation

Repack the tool after changing its source, then uninstall and install it again. Reinstalling also works when the package version has not changed.

```powershell
dotnet pack source/DeutschDotNet/DeutschDotNet.csproj --configuration Release --output source/nupkg
dotnet tool uninstall --global dotnet-de
dotnet tool install --global dotnet-de --add-source source/nupkg
```

### Run without installing

You can invoke the compiler directly from the project:

```powershell
dotnet run --project source/DeutschDotNet/DeutschDotNet.csproj -- --help
dotnet run --project source/DeutschDotNet/DeutschDotNet.csproj -- source/Examples/hallo.deu --output out --run
```

## Uninstall

Remove the globally installed tool with:

```powershell
dotnet tool uninstall --global dotnet-de
```

Uninstalling the tool does not remove assemblies it previously compiled. Remove those output files or directories yourself if they are no longer needed.

## Use the compiler

Compile a Deutsch# source file into an assembly and run it:

```powershell
dotnet-de source/Examples/hallo.deu --output out
dotnet out/hallo.dll
```

Or compile and run in one command:

```powershell
dotnet-de source/Examples/hallo.deu --output out --run
```

The compiler writes `hallo.dll` and `hallo.runtimeconfig.json` to the chosen output directory. You can also use the compiler on multiple files, a project, or a directory:

```powershell
# Compile multiple files
dotnet-de source/Examples/hallo.deu source/Examples/fibonacci.deu --output out

# Compile a project; the default output is bin/<configuration>/<target framework>
dotnet-de source/Examples/Examples.csproj --configuration Release

# Compile every .deu file under a directory tree
dotnet-de source/Examples --output out
```

### Common options

| Option | Description |
|---|---|
| `-o`, `--output <dir>` | Choose the output directory |
| `-c`, `--configuration <name>` | Choose the project configuration (default: `Debug`) |
| `-r`, `--run` | Run compiled programs after a successful compilation |
| `-q`, `--quiet` | Print errors only |
| `--version` | Print the compiler version |
| `-h`, `--help` | Show all command-line options |

## Build the repository

To build the compiler and compile the example programs:

```powershell
dotnet build source/DeutschDotNet.slnx
```

Run an example generated by the build:

```powershell
dotnet source/Examples/bin/Debug/net10.0/hallo.dll
```

See [source/README.md](source/README.md) for the language reference, more examples, diagnostics, and implementation details.
